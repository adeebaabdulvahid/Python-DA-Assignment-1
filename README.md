# Python DA Assignment 1 – Data Analysis using NumPy and Pandas

## About the Assignment

This assignment focuses on learning the basics of Python data analysis using NumPy and Pandas. It covers creating arrays, performing array operations, working with Pandas Series and DataFrames, and exploring and manipulating data.

## Topics Covered

### 1. NumPy Array Operations
- Creating 1D and 2D NumPy arrays.
- Checking array shape, data type, and size.
- Converting temperatures from Celsius to Fahrenheit.
- Finding maximum, minimum, and average temperatures.
- Array indexing and slicing.
- Extracting weekly and weekend temperature data.

### 2. Pandas Series
- Creating a Pandas Series with custom indices.
- Accessing values using `loc` and `iloc`.
- Filtering data using Boolean conditions.
- Modifying and removing Series elements.
- Calculating CGPA from marks.

### 3. Pandas DataFrame
- Creating a DataFrame using transaction data.
- Exploring data using `head()`, `tail()`, `shape`, and `dtypes`.
- Selecting specific columns.
- Filtering rows based on conditions.
- Finding value counts and unique values.
- Grouping data and calculating mean values.
- Adding, modifying, and deleting columns and rows.
